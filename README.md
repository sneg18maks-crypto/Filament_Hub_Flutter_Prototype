# Filament Hub — Flutter prototype

Кроссплатформенный UI-прототип приложения для Android и iOS.

## Что уже есть
- Главный экран со статусом принтера и карточкой катушки.
- Экран филамента: тип, цвет, влажность, остаток, температура, диаметр и рекомендуемые температуры печати.
- Экран управления: камера-заглушка, сопло/стол/камера, прогресс задания, кнопки запуска/паузы/остановки, быстрые команды.
- Каталог с открытием Printables и Thingiverse прямо внутри приложения через WebView.
- Экран Wi-Fi подключения с IP и портом.
- Разделы RFID, датчиков и удалённого доступа.

## Важно
Это визуальный прототип. Числа на карточке катушки демонстрационные, кнопки не отправляют команды, RFID и датчики не считываются, соединение с принтером не реализовано. Для реального управления нужно знать модель принтера и поддерживаемый им API/протокол (например, Moonraker/Klipper, OctoPrint или фирменный API).

## Запуск в VS Code
1. Установи Flutter SDK и Android Studio (для Android SDK).
2. В терминале выполни:
   ```bash
   flutter create filament_hub
   ```
3. Замени `pubspec.yaml` и `lib/main.dart` файлами из этого архива.
4. В папке проекта выполни:
   ```bash
   flutter pub get
   flutter run
   ```

## Сборка APK
Подключи Android-телефон с включённой отладкой по USB или запусти эмулятор:
```bash
flutter build apk --release
```
APK будет создан в `build/app/outputs/flutter-apk/app-release.apk`.

## Сборка iOS
Для iOS нужна macOS с Xcode:
```bash
flutter build ios
```

## Следующий этап разработки
1. Уточнить модель принтера и способ управления.
2. Реализовать сетевой адаптер и безопасную авторизацию.
3. Определить формат RFID-записи и тип меток/считывателя.
4. Подключить датчики влажности и температуры (если они физически предусмотрены).
5. Добавить выбор STL/3MF, слайсер или интеграцию с существующим слайсером, экспорт G-code и отправку задания.
